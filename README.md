# Ciclo do Corte

Painel móvel instalável para acompanhar o ciclo quinzenal de cortes com Igor Freitas.

- Guarda as preferências e o estado do ciclo no navegador do usuário.
- Consulta um arquivo de disponibilidade atualizado automaticamente a cada seis horas.
- Respeita a janela móvel de trinta dias da agenda.
- Ao tocar na notificação, abre a vaga no próprio app para o usuário confirmar sem voltar ao chat.
- Depois do toque em “Confirmar e reservar”, a automação confere a vaga, solicita o corte no sistema oficial e verifica se a reserva apareceu em “Meus agendamentos”.
- O nome e o telefone usados na reserva ficam como segredos do repositório; o telefone local serve apenas ao botão de consultar agendamentos.
- Um acesso limitado às ações deste repositório é entregue ao aparelho por Web Push criptografado, para que o app possa solicitar reservas sem abrir a agenda oficial.

Nenhum telefone ou dado pessoal é salvo nos arquivos públicos do repositório.
